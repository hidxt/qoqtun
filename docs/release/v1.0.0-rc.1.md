# Release v1.0.0-rc.1

首个发布候选。完整 18 阶段规划交付：核心（协议/传输/隧道/安全/统计/CLI/Desktop）、工程（CI/e2e/基准/Fuzz）、安全审计闭环。

## 亮点

- 三类隧道：TCP / UDP（session 映射+限速）/ HTTP（vhost 路由）/ HTTPS（L4 透传）。
- 安全：TLS 1.3 全链路 mTLS、Ed25519、CA 钉扎、Token 一次性+SHA-256、Server 唯一策略执行点、日志脱敏、零遥测。
- Desktop：Wails v2 + Stitch「Terra」设计包（13 页面全接线 coreapi）。
- 工程：CI 三平台矩阵、e2e 自动化、性能基准、Fuzz 语料、RC 打包（SHA256 + SBOM）。

## 安装

1. 下载对应平台归档（`qoqtun-{server,client}-v1.0.0-rc.1-{os}-{arch}.{tar.gz,zip}`）。
2. 校验：`sha256sum -c SHA256SUMS.txt`。
3. 解压即用（静态二进制）。配置见 `examples/` 与 README「快速开始」。

## 校验

- SHA256SUMS.txt 随包；SBOM.txt 含模块构建信息。
- 构建命令：`bash scripts/release.sh v1.0.0-rc.1`（`-X main.version` 注入版本）。

## 已知限制

见 docs/security/known-limitations.md（标准库漏洞需 Go 1.26.6；恶意 Server 可读明文为架构固有等）。
