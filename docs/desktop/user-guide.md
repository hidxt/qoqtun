# qoqtun Desktop 用户指南

## 启动

- 首次启动自动创建默认配置（`<用户配置目录>/qoqtun/client.toml`）。
- 主界面左侧导航：状态 / 隧道 / 新建隧道 / 服务器 / 设备入网 / 证书与身份 / 流量统计 / 日志 / 设置 / 关于。

## 快速开始（三步）

1. **设备入网**：导航到「设备入网」，输入 Server 管理员签发的一次性 Token、服务器地址、设备名称 → 入网。密钥进入系统安全存储（keystore），证书与状态写入本地（不离开设备）。
2. **服务器配置**：「服务器」填控制面地址（如 `vpn.terra.io:7000`）→ 保存（重启生效）。
3. **创建隧道**：「新建隧道」选择类型（TCP/UDP/HTTP/HTTPS）并填写本地服务 → 保存 → 「隧道」页启动/停止。

## 页面说明

| 页面 | 功能 |
|---|---|
| 状态 | 连接状态、服务器地址、实时/累计流量、活动隧道摘要 |
| 隧道 | 列表（状态/类型/本地/远端）、启停、删除（二次确认）、搜索 |
| 新建隧道 | 表单：类型切换（http 显示 Host 字段）、客户端校验、coreapi 错误回显 |
| 服务器 | 控制面地址、TLS 状态（mTLS 强制，只读） |
| 设备入网 | Token（不回显、不落盘）/地址/名称 → Enroll |
| 证书与身份 | client_id/名称/到期倒计时（≤14 天警示）/密钥存储后端 |
| 流量统计 | 累计 rx/tx、per-tunnel 连接数与流量（2s 刷新） |
| 日志 | 分级过滤、搜索、滚动（脱敏内容） |
| 设置 | 深色主题、开机启动（占位）、日志级别（占位） |
| 关于 | 版本、许可、依赖清单 |

## 安全说明

- 前端**不接触**任何私钥、证书内容、Token 明文——全部经 coreapi（返回仅元数据）。
- 传输全程 TLS 1.3 + 双向 mTLS；密钥 Ed25519 存系统 keystore。
- 日志与统计仅含元数据，无转发载荷内容。
- 桌面端不进行任何遥测/分析上报。

## 已知限制（V1）

- 配置修改（服务器地址/隧道增删）**重启后生效**（运行时启停隧道除外——见「隧道」页操作）。
- 最小化到托盘、桌面通知：V1 未支持（设置页明确标示）。
- 开机启动开关为占位（由 systemd/launchd/计划任务托管，见 docs/operations/deployment.md）。
